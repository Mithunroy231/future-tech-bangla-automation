# Future Tech বাংলা — YouTube Automation

## Goal
Build a free, Android-friendly YouTube automation system.

## Workflow
1. Discover video topics.
2. Research and verify information.
3. Generate Bengali scripts.
4. Generate narration and visuals.
5. Edit videos and add subtitles.
6. Create thumbnails and metadata.
7. Prepare a video preview.
8. Wait for owner approval.
9. Publish only after owner approval.

## Rules
- Never publish without approval.
- Never invent facts or sources.
- Use free tools wherever possible.
- Keep API credentials private.
